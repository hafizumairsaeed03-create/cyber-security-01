Module 2: Networking Fundamentals & IP Scanning

Ethical Hacking mein Networking sab se ehem step hai. Jab tak aapko network aur IP ki samajh nahi hogi, aap security audit nahi kar sakte.

🌐 Step 1: Computer Network Kya Hota Hai?
Jab do ya do se ziada devices (Mobiles, Computers, Servers) aapas mein data share karne ke liye connect hotay hain, usay Network kehte hain.

Hacker sab se pehle target ke network ki maloomat ik इकट्ठा karta hai ke us network par kitne computers ya devices active hain.
🔢 Step 2: IP Address Kya Hai? (Public vs Private)
Jaise har ghar ka ek unique address hota hai, waise hi internet par har device ka ek pehchan number hota hai jise IP Address kehte hain.
  • IPv4: Pehla format hota hai (e.g., 192.168.1.1)
  • Private IP: Aapke Wi-Fi router ke andar local devices ko milta hai.
  • Public IP: Internet par duniya bhar mein aapki pehchan hota hai.
🚪 Step 3: Ports Aur Protocols Kya Hote Hain?
Ek computer par mukhtalif services chal rahi hoti hain. Un services tak pahunchne ke darwazon ko Ports kehte hain (Total 0 se 65535 ports hote hain):
  • Port 80 (HTTP): Normal websites kholne ke liye.
  • Port 443 (HTTPS): Secure websites (Encrypted) ke liye.
  • Port 21 (FTP): Files transfer karne ke liye.
  • Port 22 (SSH): Server ko remotely control karne ke liye.
🔍 Step 4: IP Scanning Kya Hai Aur Kyun Ki Jaati Hai?
IP Scanning ka maqsad yeh dhoondna hota hai ke target system par kaun kaun se ports OPEN hain.

Agar koi kharab ya purana port khula reh jaye, to hacker usi khule darwaze (Open Port) se system mein enter hone ki koshish karta hai.
⚡ Step 5: Nmap Tool (Practical Commands)
Industry ka sab se mashhoor scanning tool Nmap (Network Mapper) hai. Kali Linux mein yeh terminal commands istemal hoti hain:
# Single IP Address Ko Scan Karna
nmap 192.168.1.1

# System Ka Operating System Aur Services Detect Karna
nmap -A 192.168.1.1

# Poore Network Ke Active Live Hosts Dhoondna (Ping Sweep)
nmap -sn 192.168.1.0/24
