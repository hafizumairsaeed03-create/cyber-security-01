Module 4: Web Application Security (OWASP Top 10)

Web Application Security mein hum websites aur web apps par mojood bugs (vulnerabilities) ko dhoondna aur unhein secure karna seekhte hain.

🌐 Step 1: OWASP Kya Hai?
OWASP ka matlab hai Open Web Application Security Project.

Yeh ek international community hai jo dunya bhar ki websites mein sab se zyada paye jane wale Top 10 Security Risks ki list har kuch saal baad release karti hai taake developers aur hackers ko security ka pata chale.
💉 Step 2: SQL Injection (SQLi) Attack
Jab website ke input fields (jaise Login form ya Search bar) mein user input filter na ho, to hacker malicious SQL Queries bhej kar Database ka full access hasil kar leta hai.
  • Impact: Passwords, User data, aur Admin access leak ho sakta hai.
# Bypass Login Form Payload Example:
' OR 1=1 --
📜 Step 3: Cross-Site Scripting (XSS)
XSS Attack mein hacker website par apna malicious JavaScript code inject karta hai. Jab koi aam user us page ko kholta hai, to woh script uske browser mein run ho jati hai.
  • Impact: Cookies theft, Session hijacking, aur User redirection.
# Basic XSS Payload Example:
<script>alert('Hacked!')</script>
🔑 Step 4: Broken Access Control & IDOR
Jab website sahi tariqay se check nahi karti ke user sirf apna data dekh raha hai ya kisi aur ka, usay Broken Access Control kehte hain.
  • IDOR Example: Direct URL parameter change karna (e.g., site.com/user?id=101 ko id=102 karke dusron ki details dekhna).
🛠️ Step 5: Web Security Tools & Defense Strategies
Web Application Security testing ke liye in tools aur defense methods ka istemal hota hai:
  • Burp Suite: Web traffic intercept karne aur requests modify karne ka sab se powerful tool.
  • SQLMap: Automated SQL Injection detection and exploitation tool.
  • Input Validation & Sanitization: User inputs ko clean aur sanitize karke database ya HTML mein bhejien.
  • Prepared Statements (Parameterized Queries): SQL Injection se bachne ka 100% effective tareeqa.
